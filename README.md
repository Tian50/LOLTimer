## LOLTimer —— 英雄联盟对局计时与语音助手

LOLTimer 是面向想要系统性提升自己的《英雄联盟》玩家设计的一款**技能与冷却管理辅助工具**。  
它可以帮助你在对局中**记录敌方英雄的技能冷却时间与关键装备 CD**，并提供**语音控制 + 精美简洁的界面**，尽量减轻手动操作负担，让你把更多精力放在操作和决策上。

---

### 功能亮点

- **技能冷却计时**
  - 为敌方英雄记录大招 / 闪现等关键技能的释放时间与预计冷却完成时间
  - 支持多路对线与团战场景，清晰展示关键冷却信息，方便一眼评估开团/抓人窗口

- **装备 CD 记录**
  - 记录敌方关键装备（如中亚、秒表、复活甲等）的使用时间与冷却
  - 帮助你判断下一波团战中对手的“保命手段”是否可用

- **语音控制（核心特色）**
  - 通过语音指令快速完成记录与标记，减少频繁点按和输入
  - 在高强度操作场景下依然可以保持对敌方冷却信息的掌控

- **界面精美、使用简单**
  - 基于 `uni-app + Vue 3` 开发，交互流程简洁直观
  - 针对移动端和多端场景优化 UI，适合放在副屏 / 平板 / 手机旁边配合游戏使用

- **账号系统（可选）**
  - 支持注册 / 登录 / 退出登录、Token 刷新等账号体系（详见 `API.md`）
  - 可扩展为云端同步数据、会员功能等

---

### 本地开发与运行

#### 1. 环境准备

- 已安装 **Node.js 16+**
- 推荐使用 **npm** 或 **pnpm / yarn**（下面以 npm 为例）
- 如尚未安装 `uni-app` CLI，可执行：

```bash
npm install -g @dcloudio/uni-app
```

#### 2. 安装依赖

在项目根目录（例如 `D:\CodeWorkSpace\LOLTimer`）执行：

```bash
npm install
```

#### 3. 启动开发环境

根据需要选择不同平台的开发命令（常用 H5 示例）：

```bash
# H5 开发
npm run dev:h5

# 微信小程序开发
npm run dev:mp-weixin

# 其他小程序 / 端参考 package.json 中的 dev:* 脚本
```

- 启动后使用对应的 `uni-app` 开发工具或浏览器访问即可预览界面与功能。

#### 4. 构建打包

```bash
# H5 构建
npm run build:h5

# 微信小程序构建
npm run build:mp-weixin

# 其他平台参考 package.json 中的 build:* 脚本
```

### 基本使用流程

- **1. 选择对局 / 英雄**
  - 打开 LOLTimer，在主页中选择或添加当前对局信息
  - 为敌方五个位置选择对应英雄（如：上单 / 打野 / 中单 / ADC / 辅助）

- **2. 记录技能与装备使用**
  - 当敌方关键技能（如闪现、大招）释放时，在界面上点击对应技能按钮进行记录  
  - 当敌方关键装备（如中亚、秒表、复活甲）使用时，同样进行记录

- **3. 使用语音控制（推荐）**
  - 根据页面提示开启语音功能  
  - 通过简单的语音指令触发记录操作（例如“记录某英雄闪现”、“记录某装备使用”等，具体指令以页面说明为准）
  - 工具会自动计算并显示下一次可用时间

- **4. 对局中参考冷却信息**
  - 通过界面或语音反馈，实时掌握敌方关键技能 / 装备的冷却情况
  - 在开团、对拼、抓人、转线前快速评估风险与机会

### 账号与后端接口（可选）

本项目已经设计好了账号系统的接口规范，后端技术栈为 **Node.js + Express + MongoDB + JWT**。  

- **认证接口包括：**
  - 注册：`POST /api/auth/register`
  - 登录：`POST /api/auth/login`
  - 退出登录：`POST /api/auth/logout`
  - 获取当前用户：`GET /api/auth/profile`
  - 刷新 Token：`POST /api/auth/refresh`
  - 健康检查：`GET /api/health`

**详细字段说明、错误码与示例代码请参考根目录的 `API.md` 文件。**
